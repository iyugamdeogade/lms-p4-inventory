# Inventory Tracker System

## Project Overview

Inventory Tracker System is a Java + JDBC based mini project developed for small businesses such as stationery shops, grocery stores, and hardware shops. The system helps manage products, vendors, stock levels, and purchase orders efficiently.

## Features

* Product management
* Vendor management
* Category management
* Stock tracking
* Low stock alerts
* Purchase order management
* JDBC CRUD operations
* HTML report generation
* MySQL database integration

## Technologies Used

* Core Java
* JDBC
* MySQL
* HTML
* Git & GitHub
